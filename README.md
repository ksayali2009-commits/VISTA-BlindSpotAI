# VISTA - Blind Spot AI

## Problem
People often overlook hidden assumptions when making decisions.

## Solution
VISTA is an AI-powered assistant that helps users identify blind spots in their reasoning.  
It supports dark/light/eye-comfort modes, allows profile creation, and maintains history of analyses.  
The system generates guiding questions to encourage critical thinking without making decisions for the user.

## Tech Stack
- Streamlit (Frontend + Deployment)
- Hugging Face Transformers (AI model)
- Python
